---
name: Usage type switching
description: Defines how account type changes affect existing user data.
---

Changing an account between student, employee, freelancer, and personal updates the account preference only. Existing spaces and tasks remain untouched, and starter templates are not inserted again.

**Why:** A user may change how they use the product after onboarding, but changing the label must not destroy their work or create duplicate template content.

**How to apply:** Keep starter-template creation exclusive to first-time onboarding. Future profile changes may adapt labels or recommendations, but must preserve user-created data unless the user explicitly requests a separate migration.
